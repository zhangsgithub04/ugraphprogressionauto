Interpretation

The path length is the number of transitions before the first state in the eventual cycle. A period-1 cycle is a fixed point up to isomorphism. Graphs are compared by exact isomorphism, not only by degree sequence or a probabilistic hash.

Deterministic ruleIsomorphism-awareMemory-only
Rule convention: all vertex degrees are computed on Gᵢ and all eligible pairs are updated simultaneously. u: toggle adjacency of equal-degree pairs; u+: add missing edges of equal-degree pairs; u−: remove existing edges of equal-degree pairs. Cycle detection uses exact graph-isomorphism checks. Canonicalization selects the lexicographically smallest upper-triangle adjacency code among a deterministic invariant-refined family of vertex orderings, with a configurable search budget; unfinished searches are explicitly marked unverified.
